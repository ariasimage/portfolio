— Cheat Sheet

CSS3

Guía rápida de las propiedades y técnicas más usadas de CSS3: selectores, caja, layout con Flexbox y Grid, responsive, variables y animaciones.

Selectores

Los selectores indican a qué elementos se aplican los estilos. Se pueden combinar para ser más precisos.

/* Etiqueta, clase e id */
p { color: #333; }
.card { padding: 1rem; }
#cabecera { position: sticky; }

/* Combinadores */
.menu a { color: #0f0f0f; }   /* descendiente */
.menu > li { display: flex; } /* hijo directo */
h2 + p { margin-top: 0; }     /* hermano adyacente */
h2 ~ p { color: #555; }       /* hermanos siguientes */

/* Pseudo-clases y pseudo-elementos */
a:hover { text-decoration: underline; }
li:nth-child(odd) { background: #eee; }
input:focus-visible { outline: 2px solid #0f0f0f; }
.boton::after { content: ' →'; }
  • La especificidad va de menos a más: etiqueta < clase < id. Evita !important.
  • Puedes agrupar selectores con comas para compartir reglas: h1, h2, h3 { ... }.
  • Las pseudo-clases usan : (estado) y los pseudo-elementos :: (parte del elemento).

Modelo de caja

Cada elemento es una caja formada por contenido, padding, borde y margen.

.card {
  width: 300px;
  padding: 1rem;
  border: 1px solid #0f0f0f;
  margin: 0 auto;
  box-sizing: border-box;
}

/* Valores abreviados */
margin: 10px 20px;                /* vertical | horizontal */
margin: 10px 20px 30px 40px;      /* arriba | derecha | abajo | izquierda */
padding: 0 1rem;

/* Reset habitual */
*, *::before, *::after { box-sizing: border-box; }
  • Con box-sizing: border-box el ancho incluye el padding y el borde.
  • margin: 0 auto centra horizontalmente un bloque con ancho definido.
  • Los márgenes verticales contiguos pueden colapsar; el padding nunca lo hace.

Tipografía

Propiedades para controlar el aspecto y la legibilidad del texto.

body {
  font-family: 'Roboto', sans-serif;
  font-size: 1rem;
  font-weight: 400;
  line-height: 1.6;
  letter-spacing: 0.5px;
}

h1 {
  font-size: 3rem;
  font-weight: 900;
  text-align: center;
  text-transform: uppercase;
}

a {
  color: inherit;
  text-decoration: underline;
  text-underline-offset: 4px;
}
  • Usa rem para los tamaños de texto: respetan la configuración del usuario.
  • line-height sin unidad (1.5 – 1.8) mejora la lectura.
  • Añade siempre una fuente genérica de respaldo (sans-serif, serif, monospace).

Colores y fondos

Formas de definir colores y de pintar fondos, imágenes y degradados.

color: #0f0f0f;                 /* hexadecimal */
color: rgb(15 15 15);           /* RGB */
color: hsl(0 0% 6%);            /* HSL */
background-color: rgb(0 0 0 / 0.5);  /* con transparencia */

.hero {
  background-image: url('img/fondo.jpg');
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}

.degradado { background: linear-gradient(to right, #0f0f0f, #444); }
.mezcla { background: color-mix(in srgb, #0f0f0f 10%, transparent); }
.suave { opacity: 0.8; }
  • Comprueba que el contraste texto/fondo cumple WCAG (mínimo 4,5:1).
  • cover rellena todo el contenedor recortando; contain muestra la imagen entera.
  • opacity afecta a todo el elemento; usa colores con alfa si solo quieres el fondo translúcido.

Display y posición

El valor de display define cómo se comporta una caja y position cómo se coloca en la página.

/* display: block, inline, inline-block, flex, grid o none */
.oculto { display: none; }

.contenedor { position: relative; }
.insignia {
  position: absolute;
  top: 0;
  right: 0;
}

.cabecera {
  position: sticky;
  top: 0;
  z-index: 1000;
}

.modal {
  position: fixed;
  inset: 0;
}
  • absolute se coloca respecto al ancestro más cercano con position distinto de static.
  • sticky necesita un valor como top para funcionar.
  • z-index solo afecta a elementos posicionados o a hijos de un contenedor flex o grid.

Flexbox

Layout en una dimensión (fila o columna) con distribución y alineación flexibles.

.contenedor {
  display: flex;
  flex-direction: row;          /* row | column */
  flex-wrap: wrap;
  justify-content: space-between;  /* eje principal */
  align-items: center;             /* eje secundario */
  gap: 1rem;
}

.item {
  flex: 1 1 calc(33.333% - 1rem);  /* grow | shrink | basis */
  min-width: 220px;
}

.especial {
  align-self: flex-end;
  order: 2;
}
  • justify-content actúa sobre el eje principal y align-items sobre el secundario.
  • Con flex: 1 1 <base> y flex-wrap: wrap las tarjetas se reparten y se apilan solas.
  • Usa gap en lugar de márgenes entre elementos.

Grid

Layout en dos dimensiones: filas y columnas a la vez.

.cuadricula {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 1rem;
}

.ancho { grid-column: span 2; }

/* Columnas responsive sin media queries */
.auto {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 1rem;
}

.pagina {
  display: grid;
  grid-template-areas:
    "cabecera cabecera"
    "lateral  principal";
}
  • Grid sirve para layouts de dos dimensiones y Flexbox para una sola dirección.
  • La unidad fr reparte el espacio disponible en fracciones.
  • repeat(auto-fit, minmax(...)) crea columnas adaptables sin media queries.

Responsive

Técnicas para que la web se adapte a cualquier tamaño de pantalla y a las preferencias del usuario.

img { max-width: 100%; height: auto; }

h1 { font-size: clamp(2rem, 6vw, 4.5rem); }

/* Mobile first: estilos base y ampliaciones con min-width */
.tarjeta { flex-direction: column; }

@media (min-width: 768px) {
  .tarjeta { flex-direction: row; }
}

@media (prefers-color-scheme: dark) {
  body { background: #121212; }
}

@media (prefers-reduced-motion: reduce) {
  * { animation: none; transition: none; }
}
  • Declara en el HTML el meta viewport; sin él, los móviles no escalan la página.
  • Mobile first: escribe primero el diseño móvil y amplía con min-width.
  • clamp(mín, ideal, máx) crea tamaños fluidos sin media queries.

Variables CSS

Las propiedades personalizadas guardan valores reutilizables y permiten crear temas.

:root {
  --color-primario: #0f0f0f;
  --color-fondo: #f2f0ec;
  --espacio-md: 1rem;
}

.tarjeta {
  padding: var(--espacio-md);
  color: var(--color-primario);
  background: var(--color-fondo);
}

/* Cambiar el tema redefiniendo variables */
.dark-mode {
  --color-primario: #ececec;
  --color-fondo: #121212;
}

/* Valor de respaldo */
.boton { color: var(--color-texto, #333); }
  • Se declaran con --nombre y se leen con var(--nombre).
  • Se heredan en cascada: redefinirlas en un ancestro cambia a todos sus descendientes.
  • Son ideales para el modo oscuro: solo cambian los valores, no las reglas.

Animaciones

Las transiciones suavizan un cambio de estado; las animaciones con keyframes definen secuencias.

.boton {
  transition: transform 0.2s ease, background-color 0.3s;
}

.boton:hover {
  transform: translateY(-4px);
}

@keyframes aparecer {
  from { opacity: 0; transform: translateY(8px); }
  to   { opacity: 1; transform: translateY(0); }
}

.panel {
  animation: aparecer 0.35s ease;
}
  • Declara la transition en el estado base, no en :hover.
  • Anima transform y opacity: son las propiedades más fluidas para el navegador.
  • Respeta prefers-reduced-motion para usuarios sensibles al movimiento.
