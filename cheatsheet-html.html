HTML5

Guía rápida de las etiquetas y atributos más usados de HTML5, con ejemplos listos para copiar.

Estructura básica

Todo documento HTML5 sigue el mismo esqueleto: declaración del tipo de documento, idioma, cabecera con metadatos y cuerpo con el contenido visible.

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Título de la página</title>
    <link rel="stylesheet" href="css/styles.css" />
  </head>
  <body>
    <script type="module" src="js/main.js"></script>
  </body>
</html>
  • <!DOCTYPE html> activa el modo estándar del navegador.
  • El atributo lang ayuda a los lectores de pantalla y a los buscadores.
  • El meta viewport es imprescindible para que la web sea responsive.

Texto y encabezados

Los encabezados estructuran el contenido por niveles y los elementos de texto aportan significado, no solo aspecto.

<h1>Título principal</h1>
<h2>Subtítulo</h2>
<p>Un párrafo con <strong>importancia</strong> y <em>énfasis</em>.</p>
<p>Línea uno<br />Línea dos</p>
<hr />
<blockquote>Una cita textual.</blockquote>
  • Usa un solo <h1> por página y no saltes niveles (h2 → h4).
  • <strong> y <em> expresan importancia y énfasis; para el aspecto usa CSS.

Enlaces e imágenes

Los enlaces conectan páginas y recursos; las imágenes necesitan siempre un texto alternativo.

<a href="contacto.html">Contacto</a>
<a href="https://developer.mozilla.org/" target="_blank" rel="noopener noreferrer">MDN</a>
<a href="mailto:hola@ejemplo.com">Escríbeme</a>

<img src="img/foto.jpg" alt="Descripción de la imagen" width="400" height="300" loading="lazy" />
  • Con target="_blank" añade siempre rel="noopener noreferrer".
  • Un alt descriptivo mejora la accesibilidad; si la imagen es decorativa, déjalo vacío (alt="").
  • width y height evitan saltos de diseño mientras carga la imagen.

Listas

Hay tres tipos de listas: sin orden, ordenadas y de definiciones.

<ul>
  <li>Elemento sin orden</li>
  <li>Otro elemento</li>
</ul>

<ol>
  <li>Primer paso</li>
  <li>Segundo paso</li>
</ol>

<dl>
  <dt>HTML</dt>
  <dd>Lenguaje de marcado de la web</dd>
</dl>
  • Los menús de navegación suelen ser listas <ul> de enlaces.
  • Solo los <li> deben ser hijos directos de <ul> y <ol>.

Etiquetas semánticas

Describen el papel de cada zona de la página, a diferencia de <div> y <span>, que no tienen significado.

<header>Cabecera del sitio</header>
<nav>Navegación principal</nav>
<main>
  <section>
    <h2>Sección</h2>
    <article>Contenido independiente</article>
  </section>
  <aside>Contenido relacionado</aside>
</main>
<footer>Pie de página</footer>
  • Solo debe haber un <main> visible por página.
  • Una <section> debería llevar un encabezado.
  • La semántica mejora el SEO y la navegación con lector de pantalla.

Formularios

Permiten recoger datos del usuario. Cada control necesita su etiqueta asociada.

<form action="/enviar" method="post">
  <label for="nombre">Nombre</label>
  <input type="text" id="nombre" name="nombre" required />

  <label for="email">Email</label>
  <input type="email" id="email" name="email" required />

  <label for="motivo">Motivo</label>
  <select id="motivo" name="motivo">
    <option value="proyecto">Proyecto</option>
    <option value="otro">Otro</option>
  </select>

  <label for="mensaje">Mensaje</label>
  <textarea id="mensaje" name="mensaje" rows="4"></textarea>

  <button type="submit">Enviar</button>
</form>
  • Enlaza cada <label> con su control mediante for e id.
  • El type correcto (email, tel, number…) activa el teclado adecuado en móvil.
  • required y pattern dan validación nativa sin JavaScript.

Tablas

Sirven para mostrar datos tabulares, no para maquetar la página.

<table>
  <caption>Lenguajes del bootcamp</caption>
  <thead>
    <tr>
      <th scope="col">Lenguaje</th>
      <th scope="col">Uso</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>HTML</td>
      <td>Estructura</td>
    </tr>
    <tr>
      <td>CSS</td>
      <td>Estilos</td>
    </tr>
  </tbody>
</table>
  • <caption> describe la tabla y scope indica si un <th> es de columna o de fila.
  • Separar <thead> y <tbody> facilita el estilo y la accesibilidad.

Multimedia

Audio, vídeo e imágenes adaptables se incrustan con etiquetas nativas.

<video src="video.mp4" controls width="480"></video>

<audio src="audio.mp3" controls></audio>

<picture>
  <source srcset="img/foto.webp" type="image/webp" />
  <img src="img/foto.jpg" alt="Descripción" />
</picture>

<iframe src="https://example.com" title="Página de ejemplo"></iframe>
  • Añade controls para que el usuario pueda reproducir y pausar.
  • <picture> permite ofrecer formatos modernos con un respaldo.
  • Todo <iframe> necesita un atributo title.

Atributos globales

Se pueden usar en cualquier etiqueta HTML.

<div id="tarjeta" class="card destacada" title="Ayuda" data-id="42" hidden>
  Contenido
</div>

<button tabindex="0" aria-label="Cerrar menú">×</button>
  • id debe ser único; class puede repetirse.
  • data-* guarda datos propios que se leen desde JavaScript con dataset.
  • aria-label da nombre accesible a controles sin texto visible.

Buenas prácticas

Hábitos que mantienen el HTML limpio, accesible y fácil de mantener.

  • Usa la etiqueta semántica adecuada antes de recurrir a <div>.
  • Escribe las etiquetas y atributos en minúsculas y usa comillas dobles.
  • Indenta con dos espacios y cierra siempre las etiquetas.
  • Valida el código con el validador del W3C y comprueba la accesibilidad.
  • Separa estructura (HTML), estilo (CSS) y comportamiento (JS).
