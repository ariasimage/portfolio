JavaScript

Guía rápida de JavaScript moderno: variables, funciones, arrays, objetos, manipulación del DOM, eventos, asincronía y módulos.

Variables y tipos de datos

Con const y let se declaran variables; los datos pueden ser primitivos u objetos.

const nombre = 'Javier';   // no se puede reasignar
let edad = 30;             // se puede reasignar
edad = 31;

// Template literals
const saludo = `Hola, ${nombre}. Tienes ${edad} años.`;

// Tipos de datos
typeof 'texto';     // 'string'
typeof 42;          // 'number'
typeof true;        // 'boolean'
typeof undefined;   // 'undefined'
typeof null;        // 'object' (rareza histórica)
typeof [];          // 'object'
typeof {};          // 'object'
Array.isArray([]);  // true
  • Usa const por defecto y let solo cuando el valor va a cambiar. Evita var.
  • Los template literals (comillas invertidas) permiten insertar expresiones con ${}.
  • typeof null devuelve "object"; para arrays usa Array.isArray().

Operadores

Aritméticos, de comparación, lógicos y los operadores modernos para valores nulos.

// Aritméticos
5 + 2;  5 - 2;  5 * 2;  5 / 2;  5 % 2;  5 ** 2;

// Comparación
5 == '5';    // true  (compara solo el valor)
5 === '5';   // false (valor y tipo)
5 !== 6;     // true

// Lógicos
true && false;   // false
true || false;   // true
!true;           // false

// Operadores modernos
const nombre = usuario?.nombre ?? 'Anónimo';
let contador = 0;
contador += 1;
contador++;
  • Usa siempre === y !==: evitan conversiones de tipo inesperadas.
  • ?. (encadenamiento opcional) evita errores al leer propiedades de null o undefined.
  • ?? solo usa el valor de la derecha si la izquierda es null o undefined, no con 0 o "".

Condicionales y bucles

Estructuras para decidir qué código se ejecuta y para repetirlo.

if (edad >= 18) {
  console.log('Adulto');
} else if (edad >= 13) {
  console.log('Adolescente');
} else {
  console.log('Niño');
}

const mensaje = edad >= 18 ? 'Adulto' : 'Menor';

switch (dia) {
  case 'lunes':
    console.log('Empieza la semana');
    break;
  default:
    console.log('Otro día');
}

for (let i = 0; i < 3; i++) { console.log(i); }
for (const fruta of frutas) { console.log(fruta); }
for (const clave in usuario) { console.log(clave); }
while (contador < 5) { contador++; }
  • for...of recorre valores (arrays, strings) y for...in recorre claves de un objeto.
  • Recuerda el break en cada case del switch para evitar que continúe con el siguiente.
  • Valores falsy: false, 0, "", null, undefined y NaN.

Funciones

Bloques de código reutilizables con distintas formas de declararlos.

function sumar(a, b) {
  return a + b;
}

const restar = function (a, b) {
  return a - b;
};

const multiplicar = (a, b) => a * b;

const saludar = (nombre = 'invitado') => `Hola, ${nombre}`;

const total = (...numeros) =>
  numeros.reduce((acumulado, n) => acumulado + n, 0);

total(1, 2, 3);   // 6
  • Las arrow functions con una sola expresión devuelven el valor sin escribir return.
  • Las arrow functions no tienen su propio this.
  • Los parámetros por defecto y el operador rest (...) simplifican funciones con argumentos variables.

Arrays

Listas ordenadas con métodos para añadir, buscar y transformar elementos.

const frutas = ['manzana', 'pera', 'uva'];

frutas.push('kiwi');      // añade al final
frutas.pop();             // quita el último
frutas.length;            // 3

frutas.map((f) => f.toUpperCase());
frutas.filter((f) => f.length > 4);
frutas.find((f) => f === 'pera');
frutas.includes('uva');   // true
[1, 2, 3].reduce((acc, n) => acc + n, 0);   // 6
frutas.forEach((f) => console.log(f));

const copia = [...frutas, 'melón'];
const [primera, segunda] = frutas;
  • map, filter y reduce devuelven un resultado nuevo y no modifican el array original.
  • push y pop sí modifican el array.
  • El operador spread (...) copia arrays y la desestructuración extrae elementos por posición.

Objetos y JSON

Colecciones de pares clave-valor para representar entidades.

const usuario = {
  nombre: 'Ana',
  edad: 28,
  saludar() {
    return `Hola, soy ${this.nombre}`;
  },
};

usuario.nombre;            // notación de punto
usuario['edad'];           // notación de corchetes
usuario.email = 'ana@ejemplo.com';
delete usuario.edad;

const { nombre, email } = usuario;
const copia = { ...usuario, activo: true };

Object.keys(usuario);
Object.values(usuario);
Object.entries(usuario);

const texto = JSON.stringify(usuario);
const objeto = JSON.parse(texto);
  • La desestructuración (const { nombre } = usuario) extrae propiedades en una línea.
  • Object.entries() devuelve un array de pares [clave, valor] fácil de recorrer.
  • JSON.stringify y JSON.parse convierten entre objetos y texto.

Manipular el DOM

Seleccionar, crear y modificar los elementos de la página desde JavaScript.

const titulo = document.querySelector('.titulo');
const items = document.querySelectorAll('.item');
const menu = document.getElementById('menu');

titulo.textContent = 'Nuevo título';
contenedor.innerHTML = `<p>${texto}</p>`;

const parrafo = document.createElement('p');
parrafo.textContent = 'Hola';
contenedor.append(parrafo);

titulo.classList.add('activo');
titulo.classList.remove('activo');
titulo.classList.toggle('oculto');

titulo.setAttribute('aria-label', 'Menú');
titulo.getAttribute('aria-label');
  • querySelector acepta cualquier selector CSS y devuelve el primer elemento; querySelectorAll devuelve todos.
  • Prefiere textContent a innerHTML cuando insertes texto de usuario: evita inyección de código.
  • Gestiona las clases con classList en lugar de editar className a mano.

Eventos

Permiten reaccionar a las acciones del usuario: clics, teclas, envío de formularios…

boton.addEventListener('click', (evento) => {
  console.log(evento.target);
});

formulario.addEventListener('submit', (evento) => {
  evento.preventDefault();   // evita recargar la página
});

document.addEventListener('DOMContentLoaded', () => {
  console.log('DOM listo');
});

// Delegación de eventos
lista.addEventListener('click', (evento) => {
  if (evento.target.matches('.item')) {
    console.log('Clic en un item');
  }
});

window.addEventListener('keydown', (evento) => {
  if (evento.key === 'Escape') cerrarMenu();
});
  • preventDefault() cancela el comportamiento por defecto, por ejemplo el envío de un formulario.
  • Con la delegación escuchas en el contenedor y funciona también con elementos creados después.
  • Usa addEventListener en lugar de atributos como onclick en el HTML.

Asincronía y fetch

Las operaciones que tardan (peticiones, temporizadores) no bloquean el resto del código.

// Promesas
fetch('https://api.ejemplo.com/datos')
  .then((respuesta) => respuesta.json())
  .then((datos) => console.log(datos))
  .catch((error) => console.error(error));

// async / await
const cargarDatos = async () => {
  try {
    const respuesta = await fetch('https://api.ejemplo.com/datos');
    if (!respuesta.ok) throw new Error(`Error ${respuesta.status}`);
    return await respuesta.json();
  } catch (error) {
    console.error(error.message);
  }
};

setTimeout(() => console.log('Pasado 1 segundo'), 1000);
  • fetch solo rechaza la promesa ante errores de red: comprueba respuesta.ok para errores HTTP.
  • await solo puede usarse dentro de una función async (o en el nivel superior de un módulo).
  • Envuelve el código con await en try...catch para gestionar los errores.

Módulos y localStorage

Los módulos dividen el código en archivos; localStorage guarda datos en el navegador.

// data/skills.js
const skills = [{ name: 'HTML' }, { name: 'CSS' }];
export default skills;
export const total = skills.length;

// main.js
import listaSkills, { total as totalSkills } from './data/skills.js';

// localStorage (solo guarda texto)
localStorage.setItem('theme', 'dark');
localStorage.getItem('theme');      // 'dark'
localStorage.removeItem('theme');

localStorage.setItem('usuario', JSON.stringify({ nombre: 'Ana' }));
const usuario = JSON.parse(localStorage.getItem('usuario'));
  • Para usar módulos carga el script con type="module" y abre la web desde un servidor (no con file://).
  • Un archivo solo puede tener un export default, pero varios export con nombre; con as renombras lo que importas.
  • localStorage conserva los datos entre sesiones y solo guarda strings: usa JSON.stringify y JSON.parse.
